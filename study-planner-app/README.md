# Study Planner: сборка APK

Внутри лежит готовый проект Capacitor с вашим планировщиком (папка `www`).
Собрать APK можно двумя способами.

## Способ 1. Без установки программ (GitHub)
1. Создайте бесплатный аккаунт на github.com и новый репозиторий.
2. Загрузите в него все файлы из этого архива, включая скрытую папку `.github`.
3. Откройте вкладку **Actions**, выберите **Build APK** и нажмите **Run workflow**.
4. Через 5-10 минут откройте завершённый запуск и скачайте `study-planner-apk` внизу страницы. Внутри будет `app-debug.apk`.

## Способ 2. На своём компьютере
Нужны Node.js 18+, JDK 17 и Android Studio.
```
npm install
npx cap add android
npx cap sync android
npx cap open android
```
В Android Studio выберите Build, Build APK(s). Файл появится в `android/app/build/outputs/apk/debug/`.

## Установка на телефон
Отправьте `app-debug.apk` на телефон и откройте его. Android попросит разрешить установку из неизвестных источников.

## Как работает сохранение
В приложении прогресс хранится на самом телефоне и остаётся после перезапуска. Облачная синхронизация между устройствами есть только в веб-версии для вошедших в аккаунт пользователей.

## Публикация в Google Play
Debug-APK подходит для личного использования и раздачи друзьям. Для Google Play нужно собрать подписанный релиз (AAB) через Android Studio, Build, Generate Signed Bundle.
